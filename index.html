Features

从一句话寒暄，到一段方案分享，到一个待解的 bug —— ChatHub 都接得住。

实时

JavaScript / Python / Swift / Rust / Go / 系统架构 / DevOps … 按爱好找组织，WebSocket 实时收发，消息历史持久化分页加载。

问答区

提问带标签、可贴代码；多人回答；问题作者可采纳最佳答案。新提问/新回答/采纳实时推送到所有客户端。

看到聊得来的伙伴，点头像直接私聊。消息双向实时推送，历史同样持久化。

管理后台

统计面板看注册/在线/消息量，封禁/解封用户（封禁即下线禁言），删违规消息/问题/回答。注册 admin 即成管理员。

⚙️

个人设置

自定义昵称与 14 色头像、浅色/深色/跟随系统主题、新消息提示音、在线状态显隐、修改密码、注销账号。

Anti-Abuse

社区得能扛得住

你担心的"乱登、刷注册、服务器炸"——这些都在防。

🚦

IP 限流

注册+登录合计每 IP 每分钟 5 次，防暴力刷 CPU。

🔒

登录失败锁定

连续错 5 次锁 15 分钟，防暴力破解密码。

📱

单设备登录

新登录自动踢掉旧 token，一号同时只一处在线。

🗑️

注销冷却

每 IP 每小时最多注销 3 次 + 二次确认，防刷建刷销。

🔑

scrypt 哈希

密码用 scrypt + 随机盐，不存明文，无法逆推。

🔨

管理员封禁

违规用户封禁即下线、禁登录禁言，内容可删。

Get Started

三步加入社区

👉 不想部署？在宣传页顶部点「🚀 现在加入（网页版）」可以直接在浏览器注册登录（需先启动下面的后端服务）。

终端 · bash
# 1. 克隆仓库
git clone https://github.com/lqdsyzh/b.git chat-hub
cd chat-hub

# 2. 启动后端（默认 http://localhost:8787）
cd backend && npm install && node server.js

# 3. 运行 macOS 客户端（需 macOS 13+ / Swift 5.9+）
cd ../ChatHub && swift run

# 用用户名 admin 注册，即自动成为首任管理员 🎉
